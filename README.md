# 🎲 Keno Master - Multi-Game Keno Platform

A professional, feature-rich Keno gaming platform built with React + Vite featuring 5 unique game modes with stunning animations, bonus features, and immersive themes.


## ✨ Live Demo

[View Live Demo](#) *(https://ydkeno.netlify.app)*

## 🎮 Game Modes

| Game | Theme | Special Features |
|------|-------|------------------|
| **Classic Keno** | Traditional Casino | Balance system, win multipliers, quick pick, win history |
| **Cleopatra Keno** | Ancient Egyptian | 12 free games, pyramid power, scarab blessing, sphinx mystery |
| **Power Keno** | High Voltage | 4x/8x multipliers, high volatility, explosive wins |
| **Multi-Card Keno** | Fast-paced | Play 4 cards simultaneously, better odds |
| **Caveman Keno** | Prehistoric | Cave bonus, combo system, wild numbers, hunt theme |

## 🚀 Features

### Core Features
- ✅ **5 Unique Game Modes** - Each with distinct mechanics and themes
- ✅ **Banking System** - Starting balance of 1000 coins with betting
- ✅ **Win Multipliers** - Up to 100x your bet
- ✅ **Bonus Systems** - Free games, multipliers, wild numbers
- ✅ **Statistics Tracking** - Win rate, biggest win, games played
- ✅ **Win History** - Last 10 games with detailed results
- ✅ **Quick Pick** - Random number selection
- ✅ **Responsive Design** - Works on desktop, tablet, and mobile

### Visual Features
- 🎨 **Glassmorphism Design** - Modern frosted glass effects
- 🌊 **Animated Backgrounds** - Dynamic floating shapes
- 🎭 **Theme-specific Styling** - Each game has unique visual identity
- ✨ **Smooth Animations** - Framer Motion powered transitions
- 📱 **Mobile Optimized** - Touch-friendly interface

## 🛠️ Tech Stack

- **Frontend:** React 18
- **Build Tool:** Vite
- **Animations:** Framer Motion
- **Icons:** React Icons
- **Styling:** CSS Modules
- **Deployment:** Netlify / Vercel

## 📦 Installation

### Prerequisites
- Node.js (v16 or higher)
- npm or yarn

### Clone & Install

```bash
# Clone the repository
git clone https://github.com/yaredabebe/keno-master.git

# Navigate to project
cd keno-master

# Install dependencies
npm install

# Start development server
npm run dev
